# Valentine Site (Kristina Edition)

Static website with separate HTML, CSS, and JavaScript files plus placeholder assets.

## Run

Open `index.html` directly in a browser, or serve this folder:

```bash
cd valentine-site
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Placeholders

- Replace `assets/images/rizzo-placeholder.svg` with your real Rizzo photo.
- Replace/add any personal photos under `assets/images/`.
- Optional music:
  1. Add `assets/audio/valentine-instrumental.mp3`.
  2. Set that path in the `<source src=\"...\">` tag in `index.html`.
